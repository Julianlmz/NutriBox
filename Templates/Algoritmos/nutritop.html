NutriTop-k

Algoritmo voraz con recursión controlada para identificar los "k" mejores alimentos sin ordenar toda la base de datos.

Complejidad: Promedio O(n) Tipo: Selección / Estadístico de Orden

¿Por qué es óptimo?

En NutriBox, a menudo necesitamos mostrar solo los "Top 10" alimentos más saludables. Ordenar miles de registros (O(n log n)) para solo tomar 10 es ineficiente.

  • Eficiencia O(n):

    Quickselect encuentra el k-ésimo elemento dividiendo la lista, similar a QuickSort pero explorando solo una mitad.

  • Estrategia Híbrida (HeapSelect):

    Para un 'k' muy pequeño, usamos un Heap (estructura voraz) para mantener solo los mejores candidatos en memoria.

  • Escalabilidad:

    Permite generar rankings en tiempo real incluso si la base de datos de alimentos crece enormemente.

Caso de Uso

Mostrar en el Dashboard el widget: "Top 5 Alimentos con más Proteína para el Desayuno" instantáneamente.

nutritop.py

import heapq

def median_of_three(a, left, right, key):
    mid = (left + right) // 2
    trio = [(key(a[left]), left), (key(a[mid]), mid), (key(a[right]), right)]
    trio.sort(key=lambda x: x[0])
    return trio[1][1]

def partition(a, left, right, pivot, key):
    pval = key(a[pivot])
    a[pivot], a[right] = a[right], a[pivot]
    i = left
    for j in range(left, right):
        if key(a[j]) > pval:
            a[i], a[j] = a[j], a[i]
            i += 1
    a[i], a[right] = a[right], a[i]
    return i

def quickselect(a, k, key):
    left, right = 0, len(a) - 1
    while left <= right:
        if right - left < 10:
            a[left:right+1] = sorted(a[left:right+1], key=key, reverse=True)
            return
        pivot = median_of_three(a, left, right, key)
        pos = partition(a, left, right, pivot, key)
        if pos == k: return
        elif pos > k: right = pos - 1
        else: left = pos + 1

def heapselect(a, k, key):
    return [x for _, x in heapq.nlargest(k, [(key(i), i) for i in a])]

def nutri_top_k(alimentos, k, key=lambda x: x["score"]):
    n = len(alimentos)
    if k >= n: return sorted(alimentos, key=key, reverse=True)
    try:
        arr = alimentos[:]
        quickselect(arr, k, key)
        return sorted(arr[:k], key=key, reverse=True)
    except:
        return heapselect(alimentos, k, key)

alimentos = [
    {"name":"Manzana","score":78},{"name":"Espinaca","score":92},
    {"name":"Arroz","score":40},{"name":"Salmón","score":95},
    {"name":"Chocolate","score":55},{"name":"Aguacate","score":90}
]

top3 = nutri_top_k(alimentos, 3)
for a in top3: print(a["name"], a["score"])
