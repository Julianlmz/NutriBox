NutriCost-Greedy

Optimización inteligente para maximizar el valor nutricional de la lonchera ajustándose a un presupuesto estricto.

Complejidad: O(n log n) Estrategia: Heurística Voraz

¿Por qué es óptimo?

Este algoritmo resuelve el problema de la "Mochila Fraccionaria" aplicado a la nutrición: obtener la mayor cantidad de "Score Nutricional" por cada peso gastado.

  • Enfoque Costo-Beneficio:

    Selecciona en cada paso el alimento con mejor relación nutrición/costo. Garantiza rapidez y buenos resultados.

  • Velocidad vs. Fuerza Bruta:

    Un algoritmo de programación dinámica sería muy lento (costoso) para este propósito en tiempo real.

  • Flexibilidad:

    Permite a los usuarios optimizar su lonchera ya sea por presupuesto financiero o tiempo de preparación.

Caso de Uso Real

Un padre tiene un presupuesto de $20.000 para la semana. El algoritmo llena la lonchera priorizando los alimentos más nutritivos que sean más baratos primero.

nutricost_greedy.py 

def nutricost_greedy(alimentos, presupuesto):
    alimentos = sorted(alimentos, key=lambda x: x["score"] / x["costo"], reverse=True)

    seleccion, costo_total, score_total = [], 0, 0

    for a in alimentos:
        if costo_total + a["costo"] <= presupuesto:
            seleccion.append(a)
            costo_total += a["costo"]
            score_total += a["score"]

    return seleccion, score_total


alimentos = [
    {"name": "Salmón", "score": 95, "costo": 12},
    {"name": "Quinoa", "score": 88, "costo": 8},
    {"name": "Yogurt", "score": 70, "costo": 5},
    {"name": "Aguacate", "score": 90, "costo": 10},
    {"name": "Manzana", "score": 80, "costo": 4}
]

menu, score = nutricost_greedy(alimentos, presupuesto=20)

print("Menú propuesto:")
for a in menu:
    print(f"- {a['name']}")

print("Puntaje total:", score)
