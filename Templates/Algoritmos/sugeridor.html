Greedy + Backtracking Híbrido

Sugeridor Inteligente

Algoritmo híbrido voraz-recursivo diseñado para encontrar combinaciones óptimas de alimentos equilibrando precisión y velocidad.

Complejidad: Promedio O(n log n) Tipo: Metaheurística

¿Por qué es óptimo?

Combina la velocidad de los algoritmos voraces con la precisión de la recursividad para personalizar menús según preferencias y restricciones.

  • Lo mejor de ambos mundos:

    Usa una estrategia Voraz para pre-seleccionar alimentos prometedores y Backtracking para validar la combinación final.

  • Equilibrio Precisión-Velocidad:

    Ideal para sistemas en tiempo real donde necesitamos respuestas rápidas pero nutricionalmente exactas.

  • Personalización Total:

    Permite adaptar las sugerencias a alergias, gustos específicos o límites calóricos estrictos.

Caso de Uso

Sugerir una lonchera que no supere las 300 calorías pero maximice el score nutricional, probando combinaciones inteligentes.

sugeridor.py 


def sugeridor_inteligente(alimentos, max_calorias):

    alimentos = sorted(alimentos, key=lambda x: x["score"] / x["calorias"], reverse=True)

    mejor_combo, mejor_score = [], 0

    def backtrack(i, combo, cal, score):
        nonlocal mejor_combo, mejor_score
        if cal <= max_calorias and score > mejor_score:
            mejor_combo, mejor_score = combo[:], score
        if i >= len(alimentos) or cal > max_calorias:
            return
        a = alimentos[i]
        backtrack(i + 1, combo + [a], cal + a["calorias"], score + a["score"])
        backtrack(i + 1, combo, cal, score)

    backtrack(0, [], 0, 0)
    return mejor_combo, mejor_score

alimentos = [
    {"name": "Manzana", "score": 80, "calorias": 50},
    {"name": "Aguacate", "score": 90, "calorias": 160},
    {"name": "Salmón", "score": 95, "calorias": 200},
    {"name": "Yogurt", "score": 70, "calorias": 80},
]

combo, score = sugeridor_inteligente(alimentos, max_calorias=300)
print("Mejor combinación:")
for a in combo: print(f"- {a['name']}")
print("Puntaje total:", score)
